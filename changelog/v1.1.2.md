班主任平台 v1.1.2 —— 集中修复 AI 批改「长时间不出结果」与「批量停不下来」两个突出问题。

本版不含新数据库字段，升级只需替换代码后重启。核心是解决推理型模型在批改时陷入超长思考、页面长时间转圈却迟迟不返回结果的问题，并让批量批改可以一键整体停止。

## 本版修复

- **AI 批改长时间无输出（重点修复）**：此前「跟随模型」档等于完全不下发思考控制参数，推理型模型（含部分商用 flash 模型）会持续思考数分钟甚至更久而始终不输出答案，页面表现为一直转圈、既不报错也不出结果。实测同一张试卷、同一模型：不干预时 6 分钟写了约 5.6 万字思考、正文 0 字；改用「关闭思考」后 **44 秒**即产出完整结果。本版让「关闭思考」真正覆盖更多服务端：
  - 同时下发多套厂商命名开关，覆盖 Qwen / 通义系、OpenAI / Gemini 兼容层、Claude 系等服务端
  - 若服务端不认识其中某个扩展参数而拒绝，会自动去掉扩展字段重发一次，**不会因此让整单批改失败**（模型名写错这类与参数无关的报错不会白白重发）
- **「限制思考」档不再必然失败**：此前该档在思考超限中止后会直接判定任务失败——因为中止时思考中还没有可提取的完整答案，而放宽重试的条件又不满足，等于设了上限反而比不设更容易失败。现在中止后会自动改用「关闭思考」重试一次，不让老师白等一场
- **批量批改可以整体停止**：批改任务是排队串行执行的（停掉当前这个，排在后面的会立刻接上开跑），因此逐个停止在批量场景下等于停不下来。现在批量进度面板新增「停止全部（N）」按钮，一次停掉正在批改的和排队等待的全部任务；停止前会提示「本次结果作废、不写入成绩，试卷图片仍保留、可随时重新发起」。单条任务原有的停止入口（任务列表里的「停止」、批改详情里的「停止批改」）保持不变
- **大图不再原样发给模型**：图片压缩此前只判断体积，凡小于阈值的图片一律跳过压缩，导致「体积不大、但长边严重超标」的试卷照片（如 4000×1846、约 2.5MB）原样发给模型，视觉处理量约为压缩后的 3 倍，明显拖长等待时间。现在统一按最长边判断，长边超标即等比缩放

## 本版改进

- **新建模型配置的默认思考模式改为「关闭思考」**：实测推理型模型在「跟随模型」下普遍会陷入长思考，而绝大多数使用者不会主动调整这一项，因此把默认值改为更稳妥的一档。**已有的模型配置不受影响，仍是原来的设置**
- **思考模式的界面说明更明确**：「跟随模型」下明确提示「此模式下思考上限不生效」，避免误以为填了上限就已生效；「关闭思考」「限制思考」的说明同步更新为当前实际行为

## Docker / GHCR 镜像

```bash
docker pull ghcr.io/kyhx1984/teacher-works:v1.1.2
```

## 快速开始

**Windows**：解压 zip → 双击 `install.bat` → 双击 `start.bat` → 访问 http://localhost:3000（admin / admin123）

**Linux / macOS**：`tar -xzf *.tar.gz && cd teacher-ops && ./start.sh`

**Docker**：解压后执行 `./deploy.sh`，或改用上面的 GHCR 镜像

## 升级与兼容性

- **无需数据迁移**：本版不含数据库结构变更，升级只需替换代码后重启：
  - Docker：解压新代码覆盖 → `docker compose restart`
  - 源码：解压覆盖 → `./stop.sh && ./start.sh`
- **已有配置零影响**：既有的模型供应商配置（含思考模式、思考上限、提示词）完全保持原样；本版只改了「新建配置」的默认值
- **建议升级后做的事**：把仍在用「跟随模型」的推理型模型改为「关闭思考」，可显著缩短等待时间；若某个模型确实需要保留推理过程，可继续用「跟随模型」，但请留意思考上限在该档下不生效
- 升级前已有的批改任务与考试记录完整保留
- 三种既有部署方式（源码 / Docker / Windows 批处理）均不受影响
- AI 批改仍为**可选功能，默认不启用**，未配置模型则完全不影响原有班级事务管理

完整变更见 [v1.1.1...v1.1.2 提交对比](https://github.com/kyhx1984/teacher-works/compare/v1.1.1...v1.1.2)。
