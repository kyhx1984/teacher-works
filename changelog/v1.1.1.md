班主任平台 v1.1.1 —— AI 试卷批改的使用体验与健壮性集中增强。

在 v1.1.0 引入「AI 试卷批改」的基础上，本版围绕老师的实际批改流程做了系统增强：从整卷批量发起、录入参考答案，到批改过程中的进度可见与随时中止，再到批改后的复核依据（每题自评把握度）、原图对照与人工修正。数据库变更全部为启动时幂等自动补列，升级**无需手工迁移**。

## 本版新增

- **批量批改整卷**：为一份试卷下所有已上传照片的学生一次性发起批改。发起前预检并列出「无照片」学生（可跳过、日后单独处理），已在批改的学生自动跳过，重复点击不会产生重复任务。整卷进度一屏可见，完成后仍走逐个查看 / 编辑 / 采纳的原有流程
- **参考答案录入（支持三种方式）**：可为试卷录入参考答案——直接粘贴文本、上传答案文件（`.txt` / `.md` / `.csv`）或上传答案图片。一次录入、多次批改复用，且不随批改任务删除而丢失。有答案时 AI 以答案为准判分；未录入则完全保持原有行为，零回归
- **每题 AI 自评把握度**：AI 为每道题给出 0~100 的把握度，界面按「≥80 有把握 / ≥60 一般 / <60 建议复核」分级标注，并在批改详情顶部汇总「平均把握度、建议复核题数、低把握题号」，帮助老师把复核精力优先放在最可能需要人工确认的题目上。导出的 Excel 同步增加「AI把握度」列与概览行
- **批改进度可观测 + 一键停止**：批改过程中除「已生成 N 字」外，新增「距上次输出秒数」「本周期新增字数」与「疑似重复输出」提示——用于区分「慢但在正常生成」与「疑似陷入循环」；同时常驻显示两道自动守护线（连续无输出 5 分钟 / 累计 45 分钟自动终止）。任一阶段都可点「停止批改」立即中止（排队中的任务同样可停），已停止的任务标记为「已停止」而非「失败」
- **图片压缩参数可配置**：上传图片的最长边、体积阈值、JPEG 质量可在「AI 模型配置」中调整，按学校网络与模型能力自行权衡清晰度与上传耗时
- **分值按大题分层展示**：批改详情与编辑界面按大题分组，组头显示该大题满分与得分小计；当模型标注的大题满分与各小题合计不符时给出醒目提醒，便于快速定位分值识别问题
- **批改详情原图常驻**：批改详情中原始试卷图片常驻可查，多图时通过缩略图切换，核对逐题判分时不必反复关闭弹窗

## 本版改进

- **默认提示词增强**：教师定位由「小学」改为「各学段、各科目」；新增「看图题与图形题识别」要求——图文结合判分、把图中关键条件写入题目描述、识别学生直接在图上作答的情况，并明确要求图意不清时不臆造数据
- **判分结果收敛**：总分 / 满分与逐题合计不一致时以逐题合计为准；分数越界自动收敛；判定与分值自相矛盾时按分值纠正，减少明显不合理的结果
- **截断兜底**：平台限制输出长度导致答案被截断时，自动放宽上限重试；中断时保留已收到的内容，必要时从模型的思考过程中打捞答案，尽量避免整单批改作废
- **思考模式三态**：可选「默认 / 限制长度 / 抑制思考」，默认不限制思考长度，避免长思考模型因额度不足而答不完
- **并发与重复保护**：批改任务排队执行（本地单模型默认串行，商用 API 可调并发）；对同一学生重复发起时复用已有任务，不重复消耗算力
- **人工修正与长期留存**：支持批改后手工修改判分与评语，人工结果最终生效并覆盖 AI 结果；逐题明细随采纳一并写入考试记录，即便日后清理批改任务，仍可在成绩档案中回看与导出

## 本版修复

- 删除仍在生成中的批改任务时，现在会一并中止，不再让进程继续等待模型空耗资源
- `.gitignore` 改为模板 `.gitignore.example`，便于各部署环境自行维护，不再强制覆盖使用方配置

## 下载说明

| 文件 | 用途 |
| --- | --- |
| `teacher-ops-1.1.1-*.zip` | **Windows 用户下载这个**（Win10 1803+ / Win11，解压后双击 `install.bat` → `start.bat`） |
| `teacher-ops-1.1.1-*.tar.gz` | Linux / macOS / Docker 部署 |
| `*.sha256` | 完整性校验，`shasum -a 256 -c <文件名>.sha256` |

便携包已内置前端构建产物，不含 node_modules，首次启动自动安装依赖。

## Docker / GHCR 镜像

```bash
docker pull ghcr.io/kyhx1984/teacher-works:v1.1.1
# 或跟随最新：docker pull ghcr.io/kyhx1984/teacher-works:latest
```

## 快速开始

**Windows**：解压 zip → 双击 `install.bat` → 双击 `start.bat` → 访问 http://localhost:3000（admin / admin123）

**Linux / macOS**：`tar -xzf *.tar.gz && cd teacher-ops && ./start.sh`

**Docker**：解压后执行 `./deploy.sh`，或改用上面的 GHCR 镜像

## 升级与兼容性

- **无需数据迁移**：本版新增的两个数据库列（`exams.answer_ref`、`exam_records.detail`）均在启动时幂等自动补齐，升级只需替换代码后重启：
  - Docker：解压新代码覆盖 → `docker compose restart`
  - 源码：解压覆盖 → `./stop.sh && ./start.sh`
- 升级前已有的批改任务与考试记录完整保留；老任务缺少本版新增字段（如把握度）时界面自动降级不显示，不影响使用
- 三种既有部署方式（源码 / Docker / Windows 批处理）均不受影响
- AI 批改仍为**可选功能，默认不启用**，未配置模型则完全不影响原有班级事务管理

完整变更见 [v1.1.0...v1.1.1 提交对比](https://github.com/kyhx1984/teacher-works/compare/v1.1.0...v1.1.1)。
