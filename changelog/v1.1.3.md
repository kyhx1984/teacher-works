班主任平台 v1.1.3 —— 学生档案四项问题修复，AI 批改接入作业管理，手机端也能拍照批改。

本版包含少量数据库结构变更（批改任务新增「来源」两列、作业新增「参考答案」一列），旧库升级时**启动自动补齐**（幂等补列，无需手动迁移），升级只需替换代码后重启。另有学生档案「学号/序号/年级班级/联系电话」四项集中修复。

## 本版修复（来自 issue #3 反馈）

- **「学号」改称「序号」，删除学生后序号连续**：学生列表与详情统一改称「序号」，列表第一列显示跨分页连续行号（删除中间学生后自动连续、不跳号），数据库 id 保持不变；花名册导出的「序号」为连续行号，同时保留 id 列作为回导匹配键，不会错位
- **年级/班级自动带出并真正入库**：此前新增/编辑/导入学生时年级和班级实际没有保存（静默丢失），本版三处全部补上；录入界面默认自动带出当前年级（全局年级设置）与当前班级（班级管理内容），仍可手动修改；历史学生的空年级/班级已自动回填
- **联系电话导入不再多出 `.0`**：Excel 里数值格式的手机号导入后会变成 `13800138000.0`（即使单元格设为文本格式也可能被解析成数值），本版导入时统一规整，只剥离「纯整数形态浮点文本」的尾缀 `.0`，不会误伤正常含小数的文本；导出侧同样净化，库里的脏值导出时也不会再传出去
- **考试记录 / 成绩导入兼容新旧两种列头**：模板与导出列头已改为「序号」，同时兼容历史文件的「学号」列头，旧 Excel 无需修改仍可正常回导

## 本版新功能

- **AI 批改接入作业管理**：作业照片可直接 AI 批改（复用作业记录里已上传的图片），参考答案支持在作业上单独设置；批改结果写回作业的分数与评语，不影响考试成绩分析。批改对象下拉按「试卷 / 作业」分组展示，批改记录带来源标签，作业列表新增「AI批改」入口
- **批改记录筛选与「实时输出」尾窗**：批改记录支持按学生 / 试卷 / 状态筛选并分页；批改详情新增实时输出尾窗，滚动展示模型最近的输出内容（区分思考与作答阶段），遇到模型空转、重复输出可一眼识别，不必再靠字数猜
- **手机端适配**：手机浏览器可正常使用，拍照上传即可批改；窄屏下侧边栏改为抽屉导航，弹窗宽度自适应、输入框防 iOS 聚焦缩放；AI 批改任务创建超时放宽至 120 秒，弱网下多图上传不易中断。桌面端布局不变

## 快速开始

**Windows**：解压 zip → 双击 `install.bat` → 双击 `start.bat` → 访问 http://localhost:3000（admin / admin123）

**Linux / macOS**：`tar -xzf *.tar.gz && cd teacher-ops && ./start.sh`

**Docker**：解压后执行 `./deploy.sh`，或改用上面的 GHCR 镜像

## 升级与兼容性

- **数据库自动迁移**：升级后首次启动自动补齐批改任务的「来源」两列与作业的「参考答案」一列（幂等、可重复执行），无需手动改库；补列失败仅影响作业批改，主流程不受影响
- **存量数据零影响**：既有批改任务自动归属「试卷」来源，原有查询、采纳、进度逻辑行为完全不变；升级前的批改任务与考试记录完整保留
- **历史 Excel 无需修改**：考试记录与成绩导入同时兼容「序号」「学号」两种列头；学生花名册如需带「序号」列的新格式，重新导出一次即可
- **建议升级后做的事**：若此前导入过学生且联系电话带 `.0` 尾缀，可先备份数据库后按「只剥纯整数尾缀」的方式清洗一次存量值（新版导出已自动净化，仅界面显示仍会带旧尾巴）；学生列表的年级/班级历史空值已自动回填，可在编辑界面按需调整
- 三种既有部署方式（源码 / Docker / Windows 批处理）均不受影响
- AI 批改仍为**可选功能，默认不启用**，未配置模型则完全不影响原有班级事务管理

完整变更见 [v1.1.2...v1.1.3 提交对比](https://github.com/kyhx1984/teacher-works/compare/v1.1.2...v1.1.3)。
